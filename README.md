This project includes code examples and results for the following paper. Please cite the paper if you use them.

    S. Kanno, I. Hamamura, R. Raymond, Q. Gao, and N. Yamamoto, Efficient implementation of randomized quantum algorithms with dynamic circuits, http://arxiv.org/abs/2503.17833.

You first replace "xxxx" in get_token_path.py to an appropriate name.  

"shadow_DS_RD.py" is a code to execute circuits for randomized measurements of a hydrogen chain model on a real device.

"get_result.py" is a code to calculate and plot expectation values for the Hartee-Fock energies using the classical shadow protocol.
